# 概览

**cyctl — 从裸机到 AI 就绪，只需几分钟** *单一二进制 · 全栈交付 · 完全离线*

## 核心特性

- **完全离线** — rootfs 镜像 + 组件离线包，无网环境一键部署
- **依赖编排** — 自动处理组件间依赖顺序，不用记哪个先装
- **AI 训练优化** — kubelet 预配置：镜像 GC 保护、并行拉取、资源预留、OOM 提前驱逐
- **弹性伸缩** — 一键添加/删除节点
- **AI Agent 友好** — JSON 输出 + 结构化错误码 + `--quiet` 模式，可被 LLM Agent 直接调用

## 工作流程

1. **构建镜像** — 从上游打包 K8s + containerd + 系统镜像为 OCI rootfs
2. **部署集群** — SSH 分发，节点初始化，kubeadm 引导，IPVS HA
3. **安装组件** — 离线包解压，按依赖顺序自动安装

集群状态持久化到本地，后续操作无需重复输入连接信息。
